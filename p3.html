About Moviw Explorer Portal

The Movie Explorer Portal is an educational static web development project Crafted specifically for the B.Tech 1st Year Web Didgning & Web Technologies Lab curruculam

The core goal of this assignment is to teach students how to take a structured HTML document containing real-world movie metadata and apply progressive styling layers using standard CSS, advanced CSS3 properties, and modern CSS frameworks like Bootstrap 5 or Tailwind CSS.

Syllabus Progression Roadmap

  1. Unit 1--HTML5 Markup: Structuring semantic web documents, metadata, lists, tables, and form inputs.
  2. Unit 2--CSS Fundamrntals:Applying external style sheets, selectors, color rules, and
  3. Unit 3--CSS3 & Responsive: Creating Fluid layouts using flexbox, CSS gride, hover transition, and media query breakpoint.
  4. Unit 4--Responsive Framework Refactoring custom CSS layouts into framework grids(Bootstrap 5/ Tailwind CSS)
